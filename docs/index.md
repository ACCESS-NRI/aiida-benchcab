# AiiDA Benchcab

`aiida-benchcab` is an [`AiiDA`][aiida] plugin package which provides workflows for
running and evaluating land surface models.

This package improves on the former [`benchcab`][benchcab] evaluation tool which
was tailored specifically for the CABLE land surface model and the NCI Gadi
supercomputer. With `aiida-benchcab`, workflows can be run on your local
computer or on a HPC cluster, and can be extended to support other land surface
models via the AiiDA plugin system.
